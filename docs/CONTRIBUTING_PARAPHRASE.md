# Contributing paraphrases

1. Read `IP_AND_PARAPHRASE_POLICY.md`.
2. Official meaning first (app / book / free PDF you own).
3. Write **new** sentences. Same triggers, timing, targets, numbers, limits.
4. Do not invent or “fix” rules.
5. Run `tools\Five-Pass-Publish-Review.ps1` before any push.
6. Prefer contributing upstream to [40kdc-data](https://github.com/wn-mitch/40kdc-data) when the change belongs there; use this repo for recovery process and coordination notes.
