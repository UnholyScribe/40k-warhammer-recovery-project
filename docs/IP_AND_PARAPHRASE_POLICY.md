# IP and paraphrase policy (hard rules)

Unholy standing rule (2026-11-25): **word it differently, mean the exact same thing.**

## Allowed

| Content | Rule |
|---|---|
| Stat lines (M, T, SV, W, LD, OC, …) | Keep as numerical facts |
| Weapon profiles (A, BS/WS, S, AP, D) | Keep as numerical facts |
| Points costs, unit sizes, keywords as labels | Keep as facts / identifiers |
| Force org / detachment structure | Keep mechanically identical |
| Ability / stratagem / enhancement **effects** | Preserve **identical game meaning** |

## Required for text

- **Do not** paste Games Workshop’s published wording from Codexes, Indexes, the App, Wahapedia scrapes, or old BSData files.
- **Do** rewrite every ability/rules blurb in **original community wording**.
- The rewrite must be a **faithful paraphrase**: same triggers, same timing, same targets, same modifiers, same restrictions, same exceptions. A player using our text and a player using the book should get the **same table result**.
- **Do not** “improve,” balance, simplify away edge cases, or invent new effects.
- **Do not** drop rare riders (“except against VEHICLE,” “once per battle,” “in your Command phase,” etc.) because they are awkward to rephrase — rephrase them.

## Paraphrase check (before commit)

1. Read official source (book / app / free PDF you legally have).
2. Write fresh prose without looking at the source sentence-by-sentence copy.
3. Diff meaning: list triggers, timing, who is affected, numbers, once-per limits.
4. Second pass: would a TO resolve a dispute the same way under both texts?
5. If unsure → mark `UNVERIFIED` / hold; do not ship.

## Forbidden to host / republish here

- Verbatim GW rules prose dumps (including DMCA’d BSData catalogue text).
- Artwork, logos, and other creative GW assets.
- Mirrors whose only purpose is “the old BSData with the same sentences.”

## Why

GW’s November 2026 DMCA focused on **copied literary expression** in data files. Mechanics-as-facts and **independently worded** descriptions of those mechanics are the rebuild lane this project uses. Changing the *meaning* is not paraphrase — that would be a different game.
